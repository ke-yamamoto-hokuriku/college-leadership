# DESIGN.md — 大学リーダーシップ研究会（College Leadership Forum）

研究会のウェブサイト・スライド・配布資料・発言録・SNS画像など、すべての意匠に共通して適用する設計基準。ブランドアイデンティティ確定版v2（2026年7月）を、AIエージェントや制作者が機械的に参照できる形に書き直したもの。この文書に書いていない判断は、確定版v2の使用規定に戻って決める。

## 0. 二つの扱い（印刷用と画面用）

同じロゴ・同じ色を使いながら、媒体で扱いを分ける。

| | 印刷用（A） | 画面用（B・ウェブサイト標準） |
|---|---|---|
| 地色 | 生成 `#f7f4ee`（紙） | ほぼ白 `#f7f8f8`、区画は白 |
| 書体 | Noto Serif JP（明朝）＋Cormorant Garamond | Noto Sans JP（ゴシック）のみ |
| 見出し | 朱の左罫＋字間広め | 藍の下罫、字間は詰める |
| 写真 | 補助 | 主要素。トップに横長1枚、一覧に3:2のサムネイル、各回ページに写真列 |
| 用途 | 配布資料、発言録、冊子、案内状 | ウェブサイト、SNS画像、画面で見せるスライド |

山本氏の判断（2026年9月）：明朝＋紙地の様式は印刷にはよいが、ディスプレイで見てよいかは別。ウェブサイトは画面用（B）を標準とする。

## 1. 全体の性格

- 落ち着き・信頼・継続性。装飾は少なく、余白と書体で品位を出す。
- 画面用では写真が主要素。会場・登壇者・討議の写真を、各回1〜3枚、キャプション付きで置く。写真がない回は同じ比率の空き枠を置き、ファイル名を示す（空のリンクや無関係な素材画像を置かない）。
- 一つの意匠の中で朱を使う面積は小さく限る。基調は深藍と地色。
- グラデーション・影・立体効果・回転をしない。角丸は 4px まで。カード風の枠を並べない。

## 3. タイポグラフィ

画面用B：Noto Sans JP 400/500/700、本文17px、行間1.85、`font-feature-settings:"palt"`。h1 36px/700、h2 22px/700＋藍の2px下罫、h3 17px/700、eyebrow 13px/700 字間.2em 深藍。欧文専用書体は使わない。

補助の文字は3段に分ける。表・登壇者の演題・引用は15px、日付・所属・注記・ナビは14px、キャプションと目盛りは13px。これより小さい字を使わない。山本氏の指摘（2026年10月）により、当初の16/14/13/12から一段ずつ引き上げた。

印刷用A：

| 役割 | 書体 | 指定 |
|---|---|---|
| 和文本文・見出し | Noto Serif JP | 400 / 600。fallback: 'Hiragino Mincho ProN', 'Yu Mincho', serif |
| 欧文・eyebrow・日付の数字 | Cormorant Garamond | 500、italic。fallback: Georgia, serif |
| 表・数値 | Noto Serif JP + `font-variant-numeric: tabular-nums` | |

- 本文 15–16px、行間 1.9。1行は全角35〜40字（約 640px）を上限。
- 主見出し（h1）28–32px、weight 600、字間 .06em。
- 節見出し（h2）15px、weight 600、字間 .3em、深藍、左に朱の3px罫。見出しの言葉は「話題」（○○について）で、主張や標語にしない。体言止め。
- eyebrow（節の上の欧文小見出し）13px、Cormorant italic、字間 .28em、朱。内容は英語の分類語（`FORUM 09`, `ARCHIVE`, `ABOUT`）。
- 欧文の全大文字には字間 .2em 以上。
- 日付の表記は「2026年7月11日（土）」。ウェブ上の西暦は算用数字、回数は「第9回」（全角数字は使わない）。

## 4. 余白・レイアウト

画面用Bの本文幅は 960px。ヘッダーは藍墨の帯（反転ロゴ＋名称＋ナビ）。トップは帯の直下に横長写真（21:9）、その下にタグライン・数字・紹介文。一覧は「日付｜内容｜サムネイル」の3列で、狭い画面では1列。各回ページは趣旨のあとに写真列（1枚なら横長、2〜3枚なら並列）。

印刷用A：

- 本文幅 880px、側の余白 28px（狭い画面では 16px 以上）。
- 節と節の間 64px。見出しと本文の間 24px。段落の間 14px。
- ページ上部は「ヘッダー（紋＋名称）→ 一本罫 → 本文」。大きなヒーロー画像を置かない。
- 情報の区切りは罫線一本で行う。枠で囲むのは表と引用だけ。
- 表：罫は罫色1px、見出し行の地は `#efe9dd`（dark: `#26324a`）、セル余白 10px 14px。
- 複数列は 2 列まで。狭い画面では1列に落とす。
- リンクは深藍、下線あり（`text-underline-offset: .2em`）。ホバーで朱。

## 5. 構成要素

### ヘッダーのナビ
「研究会一覧」「研究会について」「事務局」の3項目に、15pxの線画アイコンを添える。塗りを持たない1.4pxのストローク、色は文字と同じ（`currentColor`）、不透明度.85。一覧は3本の横線、研究会についてはiの丸、事務局は封筒。絵文字は使わない。

### ロゴ（丸に大リ紋）
- SVG の基本形をそのまま使う。円の半径92、線幅8。大とリの比率 1 : 0.38、三点内接を変えない。
- 標準色は深藍。暗色地では生成色の反転版。単色印刷は墨一色。
- 最小サイズ：紋単体 12mm（画面では 32px）。周囲に半径の1/4以上の空きを取る。
- ヘッダーではロックアップB（和文タグライン「大学を変革する、あらゆる教職員のリーダーシップ。」）を優先。

### 節（section）
```
<eyebrow>  ARCHIVE
<h2>       これまでの公開研究会
<body>
```

### 参加者アンケート
各回のページに、記述の整理（3〜4行）、満足度の表、匿名の引用3点、回答数と回答率の注記をこの順で置く。

満足度は項目名・横棒・数値の3列で示す。横棒は5点満点に対する位置を表し、必ず0から引く。4.0の位置に細い縦線を入れる。軸を途中から始めない。

トップの「研究会について」には、全回で設問が同一の2項目（全体の満足度・仕事との関連性）だけを折れ線で並べる。縦軸は1から5の全体を使う。回による差は小さく、軸を切ると実際より大きな変化に見えるため、切らない。

グラフの色は藍 `#3a6bb0` と朱 `#b14a3a`（ダークは `#5a8fd8` と `#d1694f`）。色覚特性のある方でも区別できる差を確かめたうえで選んだ組み合わせである。色だけに頼らないよう、凡例と両端の値を必ず添える。

引用は、氏名と所属機関名を出さず、職種と役職層までとする。1件2行程度、1回につき3点まで。特定の登壇者や他大学への批判的な記述は載せない。

### 開催概要（すべての回で同じ順・同じ語）
日時／会場／定員／参加費／対象／主催／共催／参加者数。項目がない回は行を省略し、順序は変えない。

参加者数は、研究会の統合参加者データ（v13）を全回共通の基準とする。表記は「70名（一般参加60名／主催・事務局7名／登壇者3名）」の形で、区分の順序を変えない。登壇者が0名の回は登壇者の項を省く。表の下に、集計の基準を示す注記を13px・鈍色で添える。過去の開催報告本文に別の数え方の人数が書かれていても、開催概要の数字はこの基準に統一する。

### 登壇者
「役割｜氏名（所属・職位）「演題」」の一行形式。所属は開催当時のもの。役割の語は次に限る。「開会挨拶」「基調講演」「特別講演」「講演」「ゲスト講演」「ビデオメッセージ」「事例報告」「実践報告」「報告」「理論的整理」「トークセッション」「パネルディスカッション」「グループワーク」「ワークショップ」「フロア・ディスカッション」「ファシリテーター」「司会」「ゲスト・コメンテーター」。

### 開催報告
段落見出しは「◆」ではなく通常の小見出し（h3、15px、weight 600）。写真はキャプション付きで、本文の間に横幅いっぱいで置く。

### 資料
「配布資料」「発言録」「アンケート結果」の三種を、この順で列挙。公開前のものは「登壇者確認後に公開」と明記し、空のリンクを置かない。

## 6. 文章

- 語尾はサイト全体で「です・ます」。
- 見出しは体言止め。行末に「推進・強化・充実・活性化・可視化・構築・展開」を置かない。
- 比喩・キャッチコピーを見出しに使わない。
- 数字・大学名・年次を入れられる箇所には入れる。
- 引用元が条件付きの記述は断定に丸めない。

## 7. 実装上の約束

- Google Fonts から書体を読み込む（画面用B：Noto Sans JP、印刷用A：Noto Serif JP と Cormorant Garamond）。それ以外の外部資源は使わない。
- 写真は `images/` に置き、`events.json` の各回 `photos` にファイル名とキャプションを書く。ファイルがあれば表示、なければ同比率の空き枠を出す。
- テーマは CSS カスタムプロパティで定義し、`:root`（light）／`prefers-color-scheme: dark`／`[data-theme]` の三段で切り替える。
- 画像は `max-width:100%`。表だけ横スクロールを許す。
- `prefers-reduced-motion` を尊重。動きは使わないのが基本。
